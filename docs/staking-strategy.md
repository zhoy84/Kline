# TRX 质押 + 做空策略计算器说明

## 核心逻辑

用户质押 TRX 获得能量租金 + 投票奖励，同时做空同等数量 TRX 来对冲本金风险，只赚取奖励部分的收益。

## 输入参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 质押价格 | $0.332 | 买入 TRX 的单价 |
| 开仓价格 | $0.332 | 做空开仓时的 TRX 价格 |
| 质押数量 | 1,649 TRX | 质押的 TRX 枚数 |
| 每日能量收入 | 0.473 TRX | 能量租赁日均收入（用户实测） |
| 每日投票收入 | 0.08 TRX | SR 投票日均奖励 |
| 已质押天数 | 60 天 | 实际已质押天数 |

## 派生计算

```
日总收入 = 每日能量收入 + 每日投票收入
已获奖励 = 日总收入 × 已质押天数
总 TRX = 质押数量 + 已获奖励
质押价值 = 质押数量 × 开仓价格
```

## 策略机制

### 做空数量规则

- **第 1 轮**：做空数量 = 质押数量（仅对冲本金）
- **第 2+ 轮**：做空数量 = 总 TRX（对冲本金 + 已获奖励，锁定利润）

### 备用金规则

备用金不由用户输入，而是**按策略自动计算**：

```
备用金 = 第1轮保证金 + 第2轮保证金 + ...
       = (n × p0 / lev1) + (totalTRX × liq1 / lev2) + ...
```

其中：
- `n` = 质押数量
- `totalTRX` = 质押数量 + 已获奖励
- `p0` = 开仓价格
- `liq1` = p0 × (1 + 1/lev1)（第 1 轮爆仓价）
- `lev1, lev2` = 各轮杠杆倍数

每轮保证金到爆仓时亏光，然后从备用金里拿下一轮的保证金重新开仓。所以备用金刚好等于所有轮次保证金之和，确保资金不浪费也不短缺。

### 爆仓价

```
爆仓价 = 开仓价 × (1 + 1/杠杆)
```

| 杠杆 | 爆仓涨幅 |
|------|---------|
| 2x | +50% |
| 3x | +33% |
| 5x | +20% |
| 10x | +10% |

### 利润来源

做空对冲了本金的涨跌，利润完全来自已获奖励 TRX 的价值变化：

```
利润 = 已获奖励 × 退出价格
收益率 = 利润 / 总投入
```

## 排序规则

排名表先按 **终局 ROI** 从高到低排，相同 ROI 时按 **首爆利润** 从高到低排。

## 明细面板三段

1. **📌 未爆仓** — 所有策略收益一致，空单正常保护
2. **🔥 爆仓链** — 本策略特有，逐轮消耗保证金的过程
3. **⚠️ 裸奔期** — 现金耗尽后无空单保护，只靠质押 TRX

## 列说明

| 列 | 含义 |
|----|------|
| 场景 | 当前处于什么阶段 |
| 杠杆 | 当前使用的做空杠杆倍数 |
| TRX 价 | 当前（或爆仓时）的 TRX 价格 |
| 平仓价值 | 现在平仓能拿回多少钱（保证金 + 短仓盈亏） |
| 涨跌幅 | 从开仓价到当前价的涨跌百分比 |
| 短仓盈亏 | 做空仓位的盈亏（正 = 赚钱，负 = 亏钱） |
| 可用现金 | 扣除当前保证金后可动用的现金 |
| 质押价值 | 总 TRX（质押 + 奖励）按当前价的价值 |
| 总资产 | 质押价值 + 可用现金 |
| 净赚 | 总资产 − 总投入 |
| ROI | 净赚 ÷ 总投入 × 100% |

## 自动交易脚本 (auto-trader.exe)

读取 `.env` 配置，通过 Binance API 自动执行 2→3x 策略：

1. 自动开 2x 空单
2. 监控爆仓状态
3. 爆仓后等待价格回调到目标位
4. 自动开 3x 空单（做空数量 = 总 TRX）
5. 创建 `close.txt` 文件可手动触发平仓

`.env` 配置项：

```
BINANCE_API_KEY=xxx
BINANCE_API_SECRET=xxx
STAKED_TRX=1649
ENTRY_PRICE=0.332
DAILY_ENERGY_TRX=0.473
DAILY_VOTE_TRX=0.08
STAKED_DAYS=60
BACKUP_USDT=547.47
PROFIT_TARGET_PCT=6.12
SYMBOL=TRXUSDT
CHECK_INTERVAL_MS=3000
LOG_FILE=auto-trader.log
```
